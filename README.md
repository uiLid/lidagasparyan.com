# lidagasparyan.com

Portfolio of Lida Gasparyan, senior product and graphic designer, Yerevan.

- `index.html` and one folder per page (for example `case-copilot/`) are the built site (English and Russian). Images are in `img/`. Rebuild with `source/build.py` (EXT=1) then `source/make_static.py`.
- `source/` holds the editable source (`src.html`), the build script and the screenshots.

Deploy: GitHub Pages, Netlify or Cloudflare Pages, with the publish directory set to the repository root.
